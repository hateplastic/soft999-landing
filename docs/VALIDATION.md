# Проверка — 18.10.2026

Проверена текущая локальная версия в отдельном headless Chrome, без подключения реальных Telegram/X-аккаунтов.

- Сборка статического `dist/`, проверка синтаксиса JavaScript, уникальности HTML ID и внутренних ссылок — успешно.
- Вкладки Обзор / Telegram / X, переключение клавиатурой, мобильное меню — успешно.
- Вёрстка на ширинах 320, 390, 768, 1024, 1440 и 1920 px; устранено горизонтальное переполнение мобильной версии.
- Просмотрены скриншоты первого экрана, панели, анимации, тарифов и кабинета.
- Анимация печати, пауза и режим reduced motion — успешно.
- Кабинет: несовпадение паролей, вход, отображение Free, выход — успешно на подменённых ответах Supabase.
- Восстановление: удаление токена из URL и запрос смены пароля — успешно на подменённых ответах. Реальные письма не отправлялись.
- Запрос кабинета не вызывает `soft_access` и не передаёт идентификатор устройства. Подготовленный SQL читает только строку auth.uid(), не пишет в базу.
- ZIP в локальном предпросмотре доступен: HTTP HEAD 200, размер файла подтверждён. Архив не копируется в репозиторий и `dist/`.
- Ошибок JavaScript в проверенных браузерных сценариях нет.

## Не проверено / не опубликовано

Серверная функция `soft_account` только подготовлена, в облаке в этой задаче не применялась. Инструмент доступа к вкладкам не инициализировался, поэтому панель Supabase не менялась. Публичная SMTP-доставка, конечные Redirect URLs, внешний релиз и Tribute ещё не настроены. Для них нужен отдельный интеграционный прогон после подключения. Кнопка публичной загрузки без downloadUrl сообщает о подготовке; Pro без purchaseUrl не принимает оплату.

GitHub-репозиторий не создавался, деплой и DNS не изменялись. Исходные проекты desktop-клиента не менялись.
